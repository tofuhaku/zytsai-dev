# my-blog

個人 blog，使用 Astro 建立，支援文章、攝影等多媒體內容。

## 技術棧

- Framework: Astro 5.x
- Styling: Tailwind CSS v4
- Deploy: Cloudflare Pages

## 開發指令

| 指令 | 說明 |
| --- | --- |
| `npm run dev` | 啟動開發伺服器（localhost:4321） |
| `npm run build` | 打包 |
| `npm run preview` | 預覽 build 結果 |
